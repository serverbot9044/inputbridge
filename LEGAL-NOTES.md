# Publishing and trademark notes

This file is practical project guidance, not legal advice.

- InputBridge is original software written independently. Do not copy code, artwork, screenshots, text, or preset data from a paid extension unless its license explicitly permits it.
- Keep **InputBridge** as the product name. Use “works with Xbox Cloud Gaming” only as a plain-text compatibility description.
- Do not use Microsoft or Xbox logos, imitate Xbox trade dress, or describe the project as official, certified, licensed, or endorsed.
- Keep the non-affiliation statement visible in the README and any extension-store listing.
- The all-rights-reserved license preserves the copyright holder's control over InputBridge. It does not grant rights to Microsoft trademarks or third-party game assets.
- Microsoft and individual games can change their technical behavior or usage rules. Publishing source code does not guarantee continued access to their services.
- InputBridge should remain an input accessibility/compatibility tool. Do not add automation, anti-cheat evasion, stat manipulation, or access-control circumvention.

Before a commercial launch or if Microsoft sends a complaint, obtain advice from a qualified intellectual-property lawyer in your jurisdiction.

Useful primary references:

- Microsoft Trademark and Brand Guidelines: https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks
- Microsoft guidance for apps that work with Microsoft products: https://learn.microsoft.com/en-us/windows/apps/publish/partner-center/trademark-and-copyright-protection
- Xbox Community Standards: https://www.xbox.com/legal/community-standards
