# Changelog

## 1.1.0 — 2026-09-14

- Renamed the project to InputBridge with independent branding.
- Moved every setting into a polished five-tab toolbar popup.
- Removed the separate settings webpage.
- Made full Xbox interface recoloring the default and expanded theme coverage.
- Added six built-in profiles plus a customizable profile.
- Added automatic title-based profile guesses and connection notices.
- Added mouse-to-right-stick input, stick ramping, diagnostics, and import/export.
- Added all-rights-reserved licensing, public-proprietary guidance, and automated validation.
