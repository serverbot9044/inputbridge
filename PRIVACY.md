# Privacy

InputBridge has no analytics, advertising, account system, remote server, or telemetry.

The extension processes keyboard and mouse events locally on Xbox website pages in order to present a virtual controller. It ignores editable text fields. Settings are stored with Chrome's extension storage APIs; Chrome may sync those settings between browsers signed into the same Chrome profile according to the user's Chrome sync configuration.

Automatic profile detection reads the visible page title locally. It does not transmit the title or browsing activity.

InputBridge requests access only to Xbox website pages, Chrome storage, and Chrome's scripting API. The scripting permission applies the user-selected theme CSS to Xbox pages; it is not used on other websites. InputBridge does not request general browsing-history access.
