# Public proprietary repository checklist

## Suggested GitHub metadata

**Repository name:** `inputbridge`

**Description:** Keyboard and mouse controller profiles for Xbox Cloud Gaming.

**Topics:** `chrome-extension`, `cloud-gaming`, `gamepad`, `keyboard-mouse`, `manifest-v3`, `xbox-cloud-gaming`

## Suggested release title

`InputBridge 1.1.0 — first public release`

## Before publishing

- Replace “InputBridge contributors” in `LICENSE` with your name or GitHub handle if you want an explicit copyright line.
- Run `npm test`.
- Load the folder unpacked and test Default, Custom, and Auto-detect in a live session.
- Set repository visibility to **Public**.
- Keep the all-rights-reserved license in the repository.
- Make clear in the repository description and README that the source is viewable but proprietary.
- Keep the non-affiliation notice in the README.
- Do not use Xbox logos or copy assets, descriptions, screenshots, source code, or preset data from other extensions.

Do not upload the packaged extension release unless you want people to be able to download it. A public source repository is sufficient for visibility.
